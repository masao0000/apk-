# Freeform Launcher

指定アプリを **フリーフォーム（フローティング）ウィンドウのまま画面ほぼ全体サイズ** で起動するランチャー。
全画面だと 60Hz に固定されるアプリ（例: LINE ディズニー ツムツム）を 120fps のまま大きく表示する目的。
対象アプリの改造・メモリ操作は一切せず、Shizuku 経由で OS 標準の `am` コマンドを叩くだけ。

## 現在の状態（v0.1.0：最小構成）
- 対象パッケージ固定：`com.linecorp.LGTMTM`（ツムツム）
- 余白（上下左右 px、初期値 4）を画面で入力可。**上だけマイナス可**（キャプションバーを画面外へ押し出す実験用）
- 起動手順
  1. `am start -W --windowingMode 5 -n <pkg>/<activity>`（Activity は PackageManager から自動取得）
  2. `am stack list` から taskId を取得
  3. `am task resize <taskId> l t r b`（画面サイズ＝回転考慮した `WindowMetrics` − 余白）
  4. 再度 `am stack list` で**実際に適用された矩形**を読み戻して表示（OS 補正の確認用）
- 実行したコマンドと出力を常に画面下に表示（デバッグ用）

次段階（実機確認後）：アプリ選択・設定保存・ホーム画面ショートカット。

## インストール
1. `release/FreeformLauncher-0.1.0.apk` を端末にダウンロード
2. ファイルアプリから開いてインストール（「提供元不明のアプリ」を許可）

## Shizuku 初回セットアップ（PC 不要・ワイヤレスデバッグ）
1. Play ストア等から **Shizuku** をインストール
2. 設定 → デバイス情報 → **ビルド番号を 7 回タップ** して開発者向けオプションを有効化
3. Wi-Fi に接続した状態で、設定 → システム → 開発者向けオプション → **ワイヤレスデバッグ** を ON
4. Shizuku を開き「ワイヤレスデバッグで起動」→「ペアリング」をタップ（通知が出る）
5. 開発者向けオプション → ワイヤレスデバッグ → **ペア設定コードによるデバイスのペア設定** を開く
6. 表示された 6 桁コードを Shizuku の通知に入力 → ペアリング完了
7. Shizuku に戻り「起動」→「実行中」になれば OK
   - 再起動後は手順 3 と 7（ワイヤレスデバッグ ON → Shizuku で起動）のみ必要

## 使い方
1. Freeform Launcher を開き「権限をリクエスト」→ Shizuku の許可ダイアログで許可
2. 余白を調整して「起動」
3. 結果に「指定」「適用」矩形とログが出る。失敗時はログをそのまま共有してください

> フリーフォームが無効な端末では、開発者向けオプションの「フリーフォーム ウィンドウを有効にする」を ON にしてください。

## ビルド
```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
署名鍵 `keystore/shared.jks`（パスワード `freeform`）は上書きインストール用に同梱した公開鍵です。
