# Freeform Launcher

指定アプリを **フリーフォーム（フローティング）ウィンドウのまま画面ほぼ全体サイズ** で起動するランチャー。
全画面だと 60Hz に固定されるアプリ（例: LINE ディズニー ツムツム）を 120fps のまま大きく表示する目的。
対象アプリの改造・メモリ操作は一切せず、Shizuku 経由で OS 標準のウィンドウ操作（`am` コマンド）を使うだけ。

## 現在の状態（v0.2.3：最小構成）
- 対象パッケージ固定：`com.linecorp.LGTMTM`（ツムツム）
- 余白（上下左右 px、初期値 4）を画面で入力可。入力値は自動保存され、次回も同じ値を使う
  - 「上端をステータスバーの下にそろえる」（既定 ON）：OS は freeform の上端をステータスバーより上に置けず、
    はみ出すとウィンドウ全体を下へずらす（下端が画面外に出る）ため、上端をステータスバー下端に合わせる
  - **上だけマイナス可（実験）**：`am task resize` は負の top を拒否するため、このときだけ
    shell 権限の `app_process` から `IActivityTaskManager.resizeTask` を直接呼ぶ。OS が補正すれば「適用」に実際の値が出る
- 起動手順
  1. `am start -W --windowingMode 5 -a MAIN -c LAUNCHER -n <pkg>/<activity>`（ホームのアイコンと同じ Intent。起動中なら前面に出すだけ）
  2. `am stack list` から taskId とウィンドウモードを取得（freeform になっていなければ理由を表示して中止）
  3. `am task resize <taskId> l t r b`（画面サイズ＝回転を考慮した `WindowMetrics` − 余白）
  4. taskId で `am stack list` を読み直し、**実際に適用された矩形**を表示（OS による補正の確認用）
- 実行したコマンドと出力を画面下に表示。「ログをコピー」で共有できる

次段階（実機確認後）：アプリ選択・設定保存・ホーム画面ショートカット。

## インストール
1. `release/FreeformLauncher-0.2.3.apk` を端末にダウンロード
   - 名前が `.apk.zip` になった場合は、ファイルアプリで `.zip` を消して `.apk` に名前を変える
2. ファイルアプリから開いてインストール（「提供元不明のアプリ」を許可）。旧版の上から上書きできる

## Shizuku 初回セットアップ（PC 不要・ワイヤレスデバッグ）
1. Play ストアから **Shizuku** をインストールし、Shizuku の**通知を許可**しておく（ペアリングコードは通知から入力する）
2. 設定 → タブレット情報（デバイス情報）→ **ビルド番号を 7 回タップ** して開発者向けオプションを有効化
3. Wi-Fi に接続した状態で、設定 → システム → 開発者向けオプション → **ワイヤレスデバッグ** を ON
   （Shizuku 公式は「USB デバッグ」も ON を推奨）
4. Shizuku を開き「ワイヤレスデバッグで起動」→「ペアリング」をタップ（通知が出る）
5. 開発者向けオプション → ワイヤレスデバッグ → **ペア設定コードによるデバイスのペア設定** を開く
6. コード画面を開いたまま、通知を引き出して 6 桁コードを Shizuku の通知に入力 → ペアリング完了
7. Shizuku に戻り「開始」→「実行中」になれば OK
   - 端末の再起動後は、手順 3（ワイヤレスデバッグ ON）と 7（Shizuku で開始）だけ必要
   - 開発者向けオプションの「ADB 承認のタイムアウトを無効にする」を ON 推奨（OFF だと 7 日間使わないと再ペアリングが必要）

## 使い方
1. Freeform Launcher を開き「権限をリクエスト」→ Shizuku の許可ダイアログで許可
2. 余白を調整して「起動」
   - Android 16（ZUI 17.5）では起動時のフリーフォーム指定が無視され全画面になることを確認済み。
     その場合は、対象アプリを手でフローティングウィンドウにしてから「リサイズのみ」を押す
   - 「診断」：起動せずに対象アプリのウィンドウモードや OS の設定をログに出す
3. 結果に「指定」「適用」矩形とログが出る。うまくいかないときは「ログをコピー」して共有してください

> フリーフォームで開かない（ログに `mode=fullscreen`）場合は、開発者向けオプションの
> 「フリーフォーム ウィンドウを有効にする」を ON にして**端末を再起動**してください（再起動まで反映されません）。

## ビルド
```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
署名鍵 `keystore/shared.jks`（パスワード `freeform`）は、作り直した APK を上書きインストールできるように
**秘密鍵ごと公開**しています。個人利用前提です。
